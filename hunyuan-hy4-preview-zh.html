模型介绍

Hy4 preview 是由腾讯混元团队研发的新一代混合专家（MoE）旗舰模型。模型总参数量 770B，每个 token 激活 49B，主干共包含78层，第一层采用标准 FFN，其余 77 层均为 MoE 结构，每层包含 256 个路由专家与 1 个共享专家，每个 token 激活 top-8 路由专家及共享专家。主干之外原生内置 1 层 MTP（总参数量 10B，激活 0.7B）以支持speculative decoding。

在架构层面，受到 DeepSeek 和 GLM 的启发，attention侧采用 Gated DeepSeek Sparse Attention（Gated DSA），并引入 IndexCache 跨层复用稀疏索引，残差侧采用 iHC (identity Hyper-Connections) 扩展层间信息通路。

新一代旗舰模型

我们从三个方面扩展了 Hy4 preview：模型规模、上下文长度和训练数据。更强的预训练与规模显著扩大的后训练相互叠加，使模型能力再次跨越一个台阶——这是我们测得的历代模型间最大提升幅度，也足以让 Hy4 preview 跻身开源前沿。

为生产力而生

我们与腾讯内部的软件工程师、游戏开发者、金融分析师和安全专家等顶尖专家合作，围绕他们实际交付的工作构建训练数据。由此，模型在这些团队每天处理的任务上取得了实质性进步：

软件工程：更擅长理解、规划、调试与验证长程开发任务，并进一步提升前端工作的视觉审美与交互质量。

办公与分析：从分散在多个文件中的杂乱上下文中提取信息，转化为可分享的文档、电子表格和演示文稿，并以更高精度处理数据分析、方程和金融模型。

游戏开发：将单条提示转化为可玩的原型，并熟练使用游戏引擎，使开发者能够通过多轮交互持续完善复杂项目。

科学研究：在困难科研问题上具备更强的理解、推理与求解能力，在 AI 研究、分子动力学、凝聚态物理和纯数学等领域取得扎实进展。

我们也持续与 CodeBuddy、WorkBuddy 等腾讯产品共同设计 Hy4 preview，让模型能力的提升体现在用户实际完成的工作中。为验证这一点，我们开展了并排盲测：163 位内部专家对 203 个工程任务的模型输出进行评分。Hy4 preview 略优于 GLM 5.3（平均分 2.99 对 2.92，胜 46.8% / 平 12.8% / 负 40.4%）和 Kimi K3（平均分 2.99 对 2.94，胜 51.2% / 平 7.9% / 负 40.9%）。

基准附录

已知局限

这是 Hy4 的早期版本。预训练与后训练仍有很大的提升空间，此次发布也存在一些已知问题，包括在复杂任务上花费过长时间推理，以及倾向于过度验证自身工作。我们会继续快速迭代。与 Hy3 preview 一样，我们希望尽早发布并了解实际使用中出现的问题——这正是 Hy3 得以大幅改进的原因，也是我们完善 Hy4 的方式。我们还将继续与腾讯产品和内部专家紧密合作，推动模型智能的边界，同时让这种能力更加充裕、价格更易负担。

快速开始

建议先通过 vLLM 或 SGLang 部署服务，然后通过 OpenAI 兼容 API 调用：

from openai import OpenAI

client = OpenAI(base_url="http://127.0.0.1:8000/v1", api_key="EMPTY")

response = client.chat.completions.create(
    model="hy4-preview",
    messages=[
        {"role": "user", "content": "Hello! Can you briefly introduce yourself?"},
    ],
    temperature=0.9,
    top_p=1.0,
)
print(response.choices[0].message.content)

推荐参数：temperature=0.9，top_p=1.0。

推理模式：默认为 "high"（深度chain-of-thought），适合数学、编程、推理等复杂任务；日常对话如需直接回复，可传入 extra_body={"chat_template_kwargs": {"reasoning_effort": "no_think"}}。

具体部署方式请参考下方推理和部署章节。

推理和部署

对于生产环境部署，我们建议使用 vLLM 或 SGLang。请参考部署方案：

  • Hy4-Preview vLLM Recipe
  • Hy4-Preview SGLang Cookbook

vLLM

使用官方预构建镜像 vllm/vllm-openai:hy4-preview：

docker run --gpus all \
  -p 8000:8000 \
  --ipc=host \
  -v ~/.cache/huggingface:/root/.cache/huggingface \
  vllm/vllm-openai:hy4-preview tencent/Hy4-preview-FP8 \
    --tensor-parallel-size 8 \
    --speculative-config '{"num_speculative_tokens":3,"method":"mtp"}' \
    --attention-backend FLASHMLA_SPARSE \
    --tool-call-parser hy_v4 \
    --reasoning-parser hy_v4 \
    --enable-auto-tool-choice \
    --port 8000 \
    --served-model-name hy4-preview

SGLang

使用官方预构建镜像 lmsysorg/sglang:hy4-preview（多架构，支持 x86 和 Arm）：

docker pull lmsysorg/sglang:hy4-preview

docker run --gpus all --ipc=host -p 8000:8000 lmsysorg/sglang:hy4-preview \
  python3 -m sglang.launch_server \
    --model tencent/Hy4-preview-FP8 \
    --tp-size 8 \
    --reasoning-parser auto \
    --tool-call-parser auto \
    --speculative-algorithm NEXTN \
    --speculative-num-steps 3 \
    --speculative-eagle-topk 1 \
    --speculative-num-draft-tokens 4 \
    --port 8000 \
    --served-model-name hy4-preview
