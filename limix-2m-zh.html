LimiX-2M：缓解表格基础模型中的低秩坍塌与 attention 瓶颈

Yuanrui Wang* 1 2、Xingxuan Zhang* 1 2、Han Yu2、Mingchao Hao1、Gang Ren1、Hao Yuan1、Li Mao1、Yunjia Zhang1、Chun Yuan2、Peng Cui† 1 2

摘要

表格基础模型（TFM）越来越能与树集成模型相媲美，但其性能往往缺乏计算效率：在标准的仿射标量 token 化方式下，每个特征基本上通过一个一维通道引入取值变化，而特征 ID／位置信号无法增加特征内部取值的自由度，导致早期层对取值的敏感性较弱，并产生冗余的隐藏状态。我们提出一个统一的 token 化与路由框架来构建强大的 TFM：RaBEL 将每个标量展开为紧凑、局部化的 RBF 特征（可选地采用指数门控），以改善条件性和浅层的有效秩；同时，重新排序的双向模块 \(S\to N\to F\) 在特征混合之前聚合跨样本上下文，并使用 attention 池化，使计算与读出对齐。这些改动共同构成了 LimiX-2M：一个具有 2M 参数的模型，在广泛使用的表格基准上超越规模更大的 TabPFN-v2 和 TabICL 基线，同时降低训练与推理成本。这些结果表明，感知取值的 token 化和与读出对齐的路由，是改善 TFM 准确率与效率权衡的关键手段。模型 checkpoint 和推理代码见 https://github.com/limix-ldm-ai/LimiX。

1. 引言

表格基础模型的最新进展——尤其是 TabPFN／TabPFN-v2（Hollmann et al., 2025; 2022）、TabICL（Qu et al., 2025）和 LimiX（Zhang et al., 2025）——已经缩小了与长期占据主导地位的基线之间的差距，并在许多情形下超过了它们。这些基线包括 gradient 提升决策树（Chen & Guestrin, 2016; Ke et al., 2017; Prokhorenkova et al., 2018）和专门的深度表格架构（Somepalli et al., 2021; Arik & Pfister, 2021）。考虑到树集成模型在中等规模表格任务上的历史优势，以及深度模型在不规则函数、重尾分布和混合数据类型上遇到的困难，这些结果十分引人注目（Grinsztajn et al., 2022）。

尽管取得了这些进展，输入 embedding 层仍是一个核心限制。主流做法是通过一个线性层映射每个标量单元格，并加入列标识（例如位置 embedding 或特征 ID embedding），TabTransformer 和 FT-Transformer 即采用这种方式（Huang et al., 2020; Gorishniy et al., 2021）。系统性分析表明，这类数值 embedding 往往限制过强，相比表达力更丰富的编码方案，仍有大量性能潜力未被利用（Gorishniy et al., 2022）。在我们的性能分析中，这种设计会在网络早期产生高度相关的激活：浅层的特征矩阵可能表现出极低的有效秩，在常见基准上有时甚至坍塌到个位数的秩。这意味着显著的参数冗余，提示我们可以用小得多的参数预算取得相当的性能。此外，它也揭示了尚未利用的表示容量：通过纠正这种秩坍塌、充分利用潜在空间，有望获得丰富得多的特征表示。

我们认为，表格基础模型的 embedding 层应在引入非线性方面发挥更大作用，让早期表示能够区分常见的表格现象，例如分段趋势、局部周期性、量化、重尾边缘分布和异方差性。为此，我们提出 RaBEL，即径向基 embedding 层，用一组局部化的非线性特征替代一次性的线性投影。经典理论与实践支持将 RBF 特征作为通用、局部化的近似器，它们与核方法紧密相关（Broomhead & Lowe, 1988; Park & Sandberg, 1991; Scholkopf & Smola, 2018; Rasmussen & Williams, 2006）。相比直接的线性 embedding，RBF 的局部性能够：（i）在不同取值区间产生多样化的激活模式；（ii）改善第一个可学习层的条件性；（iii）提高浅层表示的有效秩，而无需堆叠许多层之后才发现曲率。（接续下页。）

除了 embedding，我们还发现现有表格基础模型所用双向 attention 的排列顺序存在第二个限制。在广泛使用的设计中（例如 TabPFN 风格或 LimiX 风格的堆叠），attention 通常按特征 attention → 样本 attention 排列。这种顺序引入两个问题。（1）在第一层中，特征层面的 attention 必须仅依据原始取值整合各列，此时尚未建立任何列层面的统计量或相关性；这使 attention 缺少信息丰富的上下文，并加剧低秩坍塌。（2）预测时，许多架构仅使用最后一层的目标 token，因此在特征上计算的样本层面 attention 实际上被忽略，导致不直接影响读出的网络部分所获得的训练信号较弱。

我们通过将 attention 堆叠重新排序为样本 attention →（FFN）→ 特征 attention 来解决这些问题。输入阶段的样本 attention 使模型能够在进行特征层面 attention 之前，先聚合列层面的相关性与分布统计量（例如矩、出现频率和缺失模式）。中间的 FFN 随后压缩并调节这些信号，再由特征 attention 使用更丰富、条件性更好的输入学习特征间关系。这种排列确保所有 attention 计算都为最终预测作出贡献：样本层面汇集的信息直接塑造流向读出的特征层面表示。这一改进的机制能够更好地捕捉特征关系，并促使模型发现关键特征；我们在第 5.3 节进一步分析这一能力。

将 RaBEL 与重新排序的样本 attention → FFN → 特征 attention 架构结合，我们提出了具有 2M 参数、名为 LimiX-2M 的模型。它在主流基准上超越具有 7M 参数的 TabPFN-v2 基线，同时降低训练与推理的计算成本。这些结果表明，有理论依据的非线性 embedding 与 attention 顺序重设计相结合，可以为表格基础模型带来更好的准确率与效率权衡，以及更可靠的扩展能力。

我们的贡献总结如下。

  1. 我们诊断并量化了线性＋ID embedding 引起的低秩坍塌，并提出 RaBEL：一种紧凑、基于 RBF 的单元格编码器，可提高浅层秩并改善条件性。
  2. 我们揭示标准双向 attention（特征 attention → 样本 attention）的排列顺序问题，并引入样本 attention → FFN → 特征 attention 堆叠，以（i）在聚合特征前建立列层面的统计量；（ii）将所有 attention 信号路由至读出。
  3. 我们基于这两个组件提出具有 2M 参数的 LimiX-2M，在大多数基准上超越具有 7M 参数的 TabPFN-v2 和具有 27M 参数的 TabICL，同时降低训练与推理成本。

2. 相关工作

面向表格数据的深度模型。XGBoost、LightGBM 和 CatBoost 等 gradient 提升决策树（GBDT）长期主导表格预测（Chen & Guestrin, 2016; Ke et al., 2017; Prokhorenkova et al., 2018）。为应对这一局面，研究者提出了专门的神经网络架构。TabNet 以具有可解释性的 attention 方式选择特征（Arik & Pfister, 2021）；TabTransformer 对特征应用自 attention，对类别输入尤其有效（Huang et al., 2020）；SAINT 在特征 attention 之外加入样本间（行方向）attention 和对比预训练（Somepalli et al., 2021）。尽管有这些进展，广泛评估仍经常发现树模型在中等规模基准上具有竞争力（Grinsztajn et al., 2022），这凸显了混合数据类型和不规则目标函数带来的挑战，也推动了基础模型式的方法。

表格基础模型。TabPFN 将表格学习重新表述为上下文内推理：一个在合成任务上预训练的 Transformer 在推理时接收小型训练集，无需 gradient 更新即可预测（Hollmann et al., 2022; 2025）。TabICL 采用两阶段设计，先以特征 attention 后接行 attention 构建逐样本表示，再进行高效的上下文内推理（Qu et al., 2025）。LimiX 将表格视为特征与缺失性的联合分布，并使用掩码建模，让一个模型支持多种任务（Zhang et al., 2025）。Mitra 等近期系统（Zhang et al., 2026）探索结合合成先验的行列混合 attention，以改善跨数据集泛化。

3. 当前 embedding 中的低秩问题

TabPFN-v2 当前采用的 embedding 策略只是通过一个 \(1\times p\) 线性投影，将每个单元格（即每个标量）映射到高维隐藏空间。这种简单策略隐含地导致低秩问题：Transformer 层输出的隐藏状态往往是低秩的，尤其是在网络早期。这可能严重削弱网络的表达力，导致潜在的性能下降。本节通过理论和实验分析，揭示 TabPFN-v2 中的低秩问题。

首先，我们从理论上证明低秩问题的存在。

4. 方法

4.1. 问题设定与记号

令 \(X\in\mathbb{R}^{N\times D}\) 表示包含 \(N\) 个样本（行）和 \(D\) 个特征（列）的表格数据集。用 \(x_{i,j}\) 表示样本 \(i\) 的特征 \(j\) 的标量取值。我们的目标是将每个单元格 \(x_{i,j}\) 映射为 embedding \(e_{i,j}\in\mathbb{R}^d\)，再输入沿样本轴和特征轴执行双向 attention 的 Transformer。用 \(E\in\mathbb{R}^{N\times D\times d}\) 表示单元格 embedding 的完整张量，用 \(L\) 表示骨干网络中的 attention 模块数。

本节介绍：（i）紧凑的径向基 embedding 层 RaBEL，用于替代标量单元格的标准线性投影；（ii）重新排序的双向 attention 模块，将特征 attention → 样本 attention → FFN（简称 \(F\to S\to N\)）改为样本 attention → FFN → 特征 attention（简称 \(S\to N\to F\)），以改善条件性并确保所有 attention 计算都参与最终预测。

4.2. RaBEL：径向基 embedding 层

直接对数值单元格进行线性投影，会产生高度相关的早期激活和前几层极低的有效秩，限制下游容量。RaBEL 将非线性前置：把每个标量展开成一小组局部响应，再通过轻量投影映射到模型维度。

逐列归一化。为保证数值稳定性，我们使用 z-score 对每列进行标准化。令 \(\bar x_j\) 和 \(s_j\) 表示样本均值与标准差：

\[\tilde x_{i,j}=\frac{x_{i,j}-\bar x_j}{s_j+\epsilon},\qquad \bar x_j=\frac1N\sum_{i=1}^N x_{i,j}.\tag{1}\]

\[s_j=\sqrt{\frac1{N-1}\sum_{i=1}^N(x_{i,j}-\bar x_j)^2}.\tag{2}\]

其中，\(\epsilon>0\) 是保证数值稳定性的小常数。以下所有公式均可用于 \(x_{i,j}\) 或 \(\tilde x_{i,j}\)；为简洁起见，我们省略波浪号。

RBF 展开。对每个特征 \(j\)，选取 \(M\) 个中心 \(\{c_{j,m}\}_{m=1}^M\) 和带宽 \(\{\sigma_{j,m}\}_{m=1}^M\)。中心初始化为 \(X_{\cdot,j}\) 的经验分位数；带宽按局部变异程度（例如四分位距）成比例初始化，随后所有参数均以端到端方式学习。令第 \(m\) 个分量为 \(\kappa_{j,m}=\exp\!\left(-\frac{(x_{i,j}-c_{j,m})^2}{2\sigma_{j,m}^2}\right)\)。径向基特征映射为

\[\phi_j(x_{i,j})=[\kappa_{j,1},\ldots,\kappa_{j,M}]\in\mathbb{R}^M.\tag{3}\]

投影到模型维度。共享线性投影结合 LayerNorm，将展开的特征映射到模型宽度：

\[e_{i,j}=\operatorname{LN}(W_{\mathrm{rbf}}\phi_j(x_{i,j})+b_{\mathrm{rbf}})\in\mathbb{R}^d,\tag{4}\]

其中，\(W_{\mathrm{rbf}}\in\mathbb{R}^{d\times M}\) 和 \(b_{\mathrm{rbf}}\in\mathbb{R}^d\) 为可学习参数，并在各列之间共享。对于类别列，我们使用标准的实体 embedding 查表映射到 \(\mathbb{R}^d\)，再应用相同的 LayerNorm。

采用共享门控的指数门控 RaBEL。现实表格取值跨越多个数量级，且常具有异方差性。为使 RaBEL 感知尺度而不失去局部性，我们引入指数门控，通过统一应用于全部 \(M\) 个基函数的共享标量门控，调节 RBF 函数组的参数。

指数提取（软、可微）。固定底数 \(\beta>1\)（我们使用 \(\beta=2\)）以及小偏移 \(\tau>0\)。定义对数幅值 \(\ell_{i,j}=\log_\beta(|x_{i,j}|+\tau)\)。令 \(\mathcal B=\{b_{\min},\ldots,b_{\max}\}\subset\mathbb Z\) 为有界的指数分箱集合。通过温度控制的核构造软分配：

\[\pi_{i,j}(b)=\frac{\exp(-(\ell_{i,j}-b)^2/T)}{\sum_{b'\in\mathcal B}\exp(-(\ell_{i,j}-b')^2/T)},\quad b\in\mathcal B.\tag{5}\]

每个分箱 \(b\) 有一个可学习的 embedding \(u_b\in\mathbb R^h\)，我们还为 \(\operatorname{sgn}(x_{i,j})\) 加入符号 embedding \(u_{\mathrm{sgn}}\)。通过拼接得到尺度上下文向量 \(z^{\mathrm{exp}}_{i,j}\in\mathbb R^{h+h_s}\)：

\[z^{\mathrm{exp}}_{i,j}=\left(\sum_{b\in\mathcal B}\pi_{i,j}(b)u_b\right)\mathbin\Vert u_{\mathrm{sgn}(x_{i,j})}.\tag{6}\]

对 \((c,\sigma)\) 的共享门控。一个小型 MLP 为每个单元格产生两个正标量，在 RBF 函数组之间共享：

\[[\gamma^c_{i,j},\gamma^\sigma_{i,j}]=\operatorname{MLP}_{\mathrm{shared}}(z^{\mathrm{exp}}_{i,j})\in\mathbb R^2,\tag{7}\]

通过 Softplus 保证正值。计算以指数为条件的中心和宽度：

\[c^{(\mathrm{exp})}_{j,m}=\gamma^c_{i,j}c_{j,m},\qquad\sigma^{(\mathrm{exp})}_{j,m}=\gamma^\sigma_{i,j}\sigma_{j,m}.\tag{8}\]

门控 RBF 分量定义为：

\[\kappa^{(\mathrm{exp})}_{j,m}=\exp\!\left(-\frac{(x_{i,j}-c^{(\mathrm{exp})}_{j,m})^2}{2(\sigma^{(\mathrm{exp})}_{j,m})^2}\right).\tag{9}\]

最终的门控特征向量为：

\[\phi_j^{(\mathrm{exp})}(x_{i,j})=[\kappa^{(\mathrm{exp})}_{j,1},\ldots,\kappa^{(\mathrm{exp})}_{j,M}].\tag{10}\]

最后应用投影 \(e_{i,j}=\operatorname{LN}(W_{\mathrm{rbf}}\phi_j^{(\mathrm{exp})}(x_{i,j})+b_{\mathrm{rbf}})\)。

指数门控有三个益处：（i）尺度等变性：将输入乘以 \(\beta\) 会让 \(\ell\) 平移 1，因此门控能使 RBF 函数组适应不同数量级，产生对单位和尺度稳健的 embedding；（ii）异方差稳健性：宽度和幅值在高／低方差区间扩张／收缩，保持凸起函数有用的局部性；（iii）更好的条件性：将幅值（经指数路径）与同一数量级内的模式（经 RBF 响应）分离，能在早期层产生更高的有效秩和更平滑的 gradient。软分配 \(\pi_{i,j}\) 使模块完全可微，并避免脆弱的硬分箱。计算开销很小：额外的 \(O(|\mathcal B|)\) 核计算和一个微型两层 MLP。

4.3. 重新排序的双向 attention

表格 Transformer 的双向 attention 通常交替在特征之间（逐样本）和样本之间（逐特征）执行 attention。常见堆叠顺序为 FSN（特征 attention → 样本 attention → FFN）。这迫使最初的特征 attention 使用未经充分调节的原始取值整合各列。此外，最终预测只使用目标 token，使其他特征 embedding 以及最后的样本 attention 计算没有得到充分利用。

我们通过重新排列模块、而不引入任何额外组件，将双向模块改为 SNF（样本 attention → FFN → 特征 attention）。在这一设计中，样本 attention 层先聚合列层面的统计量和跨样本规律，轻量 FFN 调节这些信号，然后特征 attention 层基于条件性更好的输入建模特征间关系。用于预测的最终 embedding 通过对所有特征 token 进行 attention 池化得到，因此每一次 attention 计算都直接参与输出。该机制更好地捕捉特征交互，并促进关键属性的发现，第 5.3 节对此作了分析。

A. 理论分析的证明

定理 3.1 的证明。embedding 模块包含两个 \(p\) 维参数向量 \(\alpha,\beta\in\mathbb{R}^{p\times1}\)。因此，\(x_i\) 被映射为 \(z_i^T=x_i\alpha^T+\beta^T\)，输入 embedding 矩阵为 \(z^T=[z_1,z_2,\ldots,z_n]^T\in\mathbb{R}^{n\times p}\)。该矩阵的秩显然至多为 2，因为它的所有行向量都能写成 \(\alpha\) 与 \(\beta\) 的线性组合。

自 attention 的参数矩阵为 \(W_Q,W_K,W_V\in\mathbb{R}^{p\times p}\)。因此，查询 \(x_i\) 对 \(x_j\) 的 attention 得分为：

\[\begin{aligned}a_{ij}&=(x_i\alpha^T+\beta^T)W_Q\big((x_j\alpha^T+\beta^T)W_K\big)^T\\&=x_ix_j\alpha^TW_QW_K^T\alpha+x_i\alpha^TW_QW_K^T\beta+x_j\beta^TW_QW_K^T\alpha+\beta^TW_QW_K^T\beta\\&=\lambda_1x_ix_j+\lambda_2x_i+\lambda_3x_j+\lambda_4.\end{aligned}\tag{11}\]

其中，\(\lambda_1=\alpha^TW_QW_K^T\alpha\)、\(\lambda_2=\alpha^TW_QW_K^T\beta\)、\(\lambda_3=\beta^TW_QW_K^T\alpha\)、\(\lambda_4=\beta^TW_QW_K^T\beta\)。于是有：

\[\begin{aligned}\hat z_i^T&=\sum_{j=1}^n\frac{\exp(a_{ij}/\sqrt p)}{\sum_{j=1}^n\exp(a_{ij}/\sqrt p)}\cdot(x_j\alpha^T+\beta^T)W_V\\&=\left(\sum_{j=1}^n\frac{x_j\exp(a_{ij}/\sqrt p)}{\sum_{j=1}^n\exp(a_{ij}/\sqrt p)}\right)\alpha_V^T+\beta_V^T.\end{aligned}\tag{12}\]

其中，\(\alpha_V^T=\alpha^TW_V\)，\(\beta_V^T=\beta^TW_V\)。可以看到，\(z_i\) 同样可以写成两个向量 \(\alpha_V\) 和 \(\beta_V\) 的线性组合，因此输出的秩至多为 2。对于多头 attention，每个头的计算与标准自 attention 完全相同。用 \(W_O^{(h)}\) 表示头 \(h\) 的输出投影矩阵，输出投影为：

\[\begin{aligned}\hat z_i&=\sum_{h=1}^H\hat z_{i,h}^TW_O^{(h)}=\sum_{h=1}^H(\mu_{i,h}\alpha_V^{(h)}+\beta_V^{(h)})^TW_O^{(h)}\\&=\sum_{h=1}^H(\mu_{i,h}\alpha_O^{(h)}+\beta_O^{(h)})^T\\&=\sum_{h=1}^H(\mu_{i,h}\alpha_O^{(h)})^T+\beta_O^T.\end{aligned}\tag{13}\]

因此，\(\hat z_i\) 可以写成 \(H+1\) 个向量的线性组合，这意味着输出的秩至多为 \(H+1\)。

B. 标准标量 embedding 下的取值敏感性坍塌

本节解释常见 TFM 中的一种结构性低效：即使存在特征标识／位置信号，标准标量 token 化仍通过维度极低的通道注入每个取值 \(x_{i,j}\)。这会导致早期层对取值的敏感性较弱、冗余较高，使扩大宽度 \(d\) 的效率低下。我们将这一瓶颈形式化，并推导由机制出发的诊断指标；我们提出的 RaBEL tokenizer 和重新排序的双向 attention 正是为解决这些问题而设计的。

B.1. 问题设定与符号

令 \(X\in\mathbb{R}^{N\times D}\) 表示包含 \(N\) 个样本（行）和 \(D\) 个特征（列）的表格数据集。用 \(x_{i,j}\) 表示样本 \(i\)、特征 \(j\) 的标量值。我们的目标是把每个单元格 \(x_{i,j}\) 映射为 embedding \(e_{i,j}\in\mathbb{R}^d\)，并将其输入沿样本轴和特征轴执行双向 attention 的 transformer。我们用 \(E\in\mathbb{R}^{N\times D\times d}\) 表示完整的单元格 embedding 张量，用 \(L\) 表示骨干网络中的 attention 模块数。

仅依赖特征的信号（ID／位置）。许多 TFM 会添加一个只依赖特征索引 \(j\) 的可学习向量（特征 ID、位置信号等）。我们引入一个仅依赖特征的辅助向量 \(a_j\in\mathbb{R}^d\)（若不存在，则令 \(a_j\equiv0\)）。关键在于，\(a_j\) 不包含任何关于取值 \(x_{i,j}\) 的信息。

B.2. 基线：仿射标量 token 化意味着一维取值通道

我们分析数值单元格广泛采用的一种基线：直接线性投影（通常随后使用 LayerNorm），可选地再加上仅依赖特征的信号。具体定义如下：

\[e_{i,j}^{\mathrm{lin}}=\mathrm{LN}(W_{\mathrm{lin}}x_{i,j}+b_{\mathrm{lin}})+a_j,\quad W_{\mathrm{lin}}\in\mathbb{R}^{d\times1},\ b_{\mathrm{lin}}\in\mathbb{R}^d.\tag{14}\]

令 \(E^{\mathrm{lin}}\in\mathbb{R}^{N\times D\times d}\) 表示其 \((i,j)\) 项为 \(e_{i,j}^{\mathrm{lin}}\) 的张量。

关键并非 ID“毫无作用”——它们能够区分列——而是它们无法增加取值进入模型时所经过通道的内在维度。理解这一点的正确方式，是去除仅依赖特征的偏移，并分离特征内部的取值变化。

特征内部中心化。对于任意 embedding 张量 \(E\in\mathbb{R}^{N\times D\times d}\)，将各样本的 embedding 堆叠，定义特征 \(j\) 的切片 \(E_{:,j,:}\in\mathbb{R}^{N\times d}\)。定义逐特征均值与中心化 embedding：

\[\bar e_j=\frac1N\sum_{i=1}^Ne_{i,j}\in\mathbb{R}^d,\qquad\tilde e_{i,j}=e_{i,j}-\bar e_j,\qquad\tilde E_j\in\mathbb{R}^{N\times d}:(\tilde E_j)_{i,:}=\tilde e_{i,j}^{\top}.\tag{15}\]

根据构造，任何仅依赖特征的向量 \(a_j\) 都会在 \(\tilde e_{i,j}\) 中抵消。

有效秩。对于奇异值为 \(\{s_k\}\) 的矩阵 \(A\)，定义有效秩：

\[r_{\mathrm{eff}}(A)=\exp\left(-\sum_kp_k\log p_k\right),\qquad p_k=\frac{s_k}{\sum_\ell s_\ell}.\tag{16}\]

我们用 \(r_{\mathrm{eff}}(\tilde E_j)\) 量化特征 \(j\) 内由取值引起的变化的维度。

定理 B.1（ID 不会增加特征内部取值维度）。考虑基线 tokenizer：

\[e_{i,j}^{\mathrm{lin}}=\mathrm{LN}(W_{\mathrm{lin}}x_{i,j}+b_{\mathrm{lin}})+a_j,\quad W_{\mathrm{lin}}\in\mathbb{R}^{d\times1},\ b_{\mathrm{lin}}\in\mathbb{R}^d,\ a_j\in\mathbb{R}^d,\tag{17}\]

并定义 LayerNorm 之前的向量：

\[z_{i,j}^{\mathrm{lin}}=W_{\mathrm{lin}}x_{i,j}+b_{\mathrm{lin}}\in\mathbb{R}^d.\tag{18}\]

对于任意特征 \(j\)，将 \(\{z_{i,j}^{\mathrm{lin}}\}_{i=1}^N\) 沿样本中心化，得到 \(\tilde Z_j^{\mathrm{lin}}\in\mathbb{R}^{N\times d}\)：

\[(\tilde Z_j^{\mathrm{lin}})_{i,:}=\left(z_{i,j}^{\mathrm{lin}}-\frac1N\sum_{i'=1}^Nz_{i',j}^{\mathrm{lin}}\right)^{\top}.\tag{19}\]

则 \(\mathrm{rank}(\tilde Z_j^{\mathrm{lin}})\leq1\)。等价地，对于任意 \(i,i'\)，

\[z_{i,j}^{\mathrm{lin}}-z_{i',j}^{\mathrm{lin}}=W_{\mathrm{lin}}(x_{i,j}-x_{i',j})\in\mathrm{span}(W_{\mathrm{lin}}),\tag{20}\]

并且，任何加性的、仅依赖特征的向量 \(a_j\) 都会在沿 \(i\) 的特征内部中心化中精确抵消。

证明。固定一个特征索引 \(j\in[D]\)。我们证明三个结论：（i）\(z_{i,j}^{\mathrm{lin}}\) 的显式中心化形式；（ii）秩上界 \(\mathrm{rank}(\tilde Z_j^{\mathrm{lin}})\leq1\)；（iii）仅依赖特征的偏移 \(a_j\) 在特征内部中心化中的抵消。

根据定义（18），

\[\frac1N\sum_{i'=1}^Nz_{i',j}^{\mathrm{lin}}=\frac1N\sum_{i'=1}^N(W_{\mathrm{lin}}x_{i',j}+b_{\mathrm{lin}})=W_{\mathrm{lin}}\frac1N\sum_{i'=1}^Nx_{i',j}+b_{\mathrm{lin}}.\]

定义特征 \(j\)（沿样本）的经验均值为：

\[\bar x_j=\frac1N\sum_{i=1}^Nx_{i,j}.\tag{21}\]

于是，\(\{z_{i,j}^{\mathrm{lin}}\}\) 的特征内部均值为：

\[\bar z_j\triangleq\frac1N\sum_{i=1}^Nz_{i,j}^{\mathrm{lin}}=W_{\mathrm{lin}}\bar x_j+b_{\mathrm{lin}}.\tag{22}\]

用（18）减去（22），对于每个 \(i\in[N]\)，得到：

\[z_{i,j}^{\mathrm{lin}}-\bar z_j=(W_{\mathrm{lin}}x_{i,j}+b_{\mathrm{lin}})-(W_{\mathrm{lin}}\bar x_j+b_{\mathrm{lin}})=W_{\mathrm{lin}}(x_{i,j}-\bar x_j).\tag{23}\]

所以 \(a_j\) 精确抵消。将这一结论应用于（17），可知任何特征 ID／位置向量 \(a_j\) 都不会对沿 \(i\) 的特征内部变化产生贡献。

解释（“取值瓶颈”）。定理 B.1 表明，在归一化之前，每个特征通过一维通道注入取值变化，与宽度 \(d\) 无关。ID／位置信号能够区分特征（通过使均值沿 \(j\) 偏移），但无法增加特征内部取值的自由度，因为它们不依赖 \(x_{i,j}\)，并在（15）中消失。这预示着较低的 \(r_{\mathrm{eff}}(\tilde E_j^{\mathrm{lin}})\) 和高度相关的早期激活。

LayerNorm 不会消除瓶颈，而会在局部重塑它。LayerNorm 是非线性的，但在一个 batch 周围的局部区域可以进行一阶近似。令 \(J_{\mathrm{LN}}(z)\in\mathbb{R}^{d\times d}\) 表示 LN 在 \(z\) 处的 Jacobian。对于 \(x_{i,j}\) 的微小扰动，

\[\delta\mathrm{LN}(z_{i,j}^{\mathrm{lin}})\approx J_{\mathrm{LN}}(z_{i,j}^{\mathrm{lin}})W_{\mathrm{lin}}\,\delta x_{i,j}.\tag{26}\]

因此，局部由取值引起的切向方向仍被限制在 \(J_{\mathrm{LN}}(\cdot)W_{\mathrm{lin}}\) 的张成空间中，相对于 \(d\) 而言，该空间通常维度较低。简言之，增大宽度可能使冗余的增长快于取值敏感性的增长。

B.3. 对浅层模块的影响：低维的取值敏感性

令 \(H^{(\ell)}\in\mathbb{R}^{N\times D\times d}\) 表示经过 \(\ell\in\{0,1,\ldots,L\}\) 个 attention 模块之后的隐藏张量，其中 \(H^{(0)}=E\)。为衡量特征 \(j\) 能在多少个独立方向上影响表示，我们定义取值敏感性 Jacobian。

取值敏感性 Jacobian。对于固定特征 \(j\)，定义：

\[J_j^{(\ell)}=\left[\frac{\partial\mathrm{vec}(H^{(\ell)})}{\partial x_{1,j}},\frac{\partial\mathrm{vec}(H^{(\ell)})}{\partial x_{2,j}},\ldots,\frac{\partial\mathrm{vec}(H^{(\ell)})}{\partial x_{N,j}}\right]\in\mathbb{R}^{(NDd)\times N},\tag{27}\]

并使用 \(r_{\mathrm{eff}}(J_j^{(\ell)})\) 作为取值敏感性的诊断指标。

命题 B.2（仿射 token 化限制局部取值敏感性（局部线性化））。考虑一个数值特征 \(j\)，令标量 tokenizer 为：

\[e_{i,j}=\mathrm{LN}(wx_{i,j}+b)+a_j,\]

其中 \(w,b,a_j\in\mathbb{R}^d\)，LayerNorm 使用固定的增益和偏置参数。

现在考虑一个具有 \(H\) 个 attention 头的第一层样本 attention 模块，它作用于序列：

\[\{e_{1,j},\ldots,e_{N,j}\}.\]

对于任意输出位置 \(t\)，定义输出 token 相对于 \(N\) 个样本中特征 \(j\) 的取值的 Jacobian：

\[K_{t,j}=\left[\frac{\partial h^{(1)}_{t,j,:}}{\partial x_{1,j}},\ldots,\frac{\partial h^{(1)}_{t,j,:}}{\partial x_{N,j}}\right]\in\mathbb{R}^{d\times N}.\]

则存在一个线性子空间 \(U_j\subseteq\mathbb{R}^d\)，与 \(t\) 及具体扰动方向无关，使得：

\[\dim(U_j)\leq2H,\]

并且：

\[\frac{\partial h^{(1)}_{t,j,:}}{\partial x_{k,j}}\in U_j,\qquad\forall t,k\in\{1,\ldots,N\}.\]

因此，

\[\mathrm{rank}(K_{t,j})\leq2H\qquad\text{对于每个 }t.\]

如果将所有输出位置 \(t=1,\ldots,N\) 的 Jacobian 堆叠，则得到完整的第一层取值敏感性 Jacobian：

\[J_j^{\mathrm{attn}}\in\mathbb{R}^{Nd\times N},\]

它满足：

\[\mathrm{rank}(J_j^{\mathrm{attn}})\leq2HN.\]

此外，若在这个 attention 子层之后接入任意在工作点进行线性化的模块，例如 FFN 的一阶近似或特征混合映射 \(L\)，则：

\[\mathrm{rank}(LJ_j^{\mathrm{attn}})\leq\mathrm{rank}(J_j^{\mathrm{attn}})\leq2HN.\]

尤其是，这一上界与隐藏宽度 \(d\) 无关。因此，仅增大宽度不会自动增加浅层中可用的取值敏感方向数。

证明。步骤 1：tokenizer 将依赖取值的变化限制在至多二维的仿射子空间内。

令：

\[z(x)=wx+b.\]

记：

\[\bar w=\frac1d\mathbf1^{\top}w,\qquad\bar b=\frac1d\mathbf1^{\top}b,\]

并定义中心化向量：

\[u=w-\bar w\mathbf1,\qquad v=b-\bar b\mathbf1.\]

那么，中心化的归一化前 token 为：

\[z(x)-\frac1d(\mathbf1^{\top}z(x))\mathbf1=xu+v.\]

因此，LayerNorm 可以写成：

\[\mathrm{LN}(z(x))=\beta+\frac{D_\gamma(xu+v)}{\sigma(x)},\]

其中 \(D_\gamma=\mathrm{diag}(\gamma)\)，并且：

\[\sigma(x)=\sqrt{\frac1d\|xu+v\|_2^2+\varepsilon}.\]

定义：

\[u'=D_\gamma u,\qquad v'=D_\gamma v.\]

则：

\[e_{i,j}=a_j+\beta+\alpha_i u'+\eta_i v',\]

其中标量 \(\alpha_i,\eta_i\) 依赖 \(x_{i,j}\)。因此，对于固定特征 \(j\)，所有 token \(\{e_{i,j}\}_{i=1}^N\) 都位于仿射子空间：

\[c_j+\mathrm{span}\{u',v'\},\qquad c_j:=a_j+\beta.\]

因此，tokenizer 输出中依赖取值的部分被限制在一个维度至多为 2 的子空间内。

这已经表明，特征标识 \(a_j\) 不会扩展取值敏感子空间：它只会改变仿射偏移。

解释。该命题形式化了低取值敏感性背后的关键观点：

  • 标准仿射标量 tokenizer 通过极少数方向注入一个数值特征的取值；
  • 自 attention 能够混合样本，但无法凭空从如此狭窄的输入通道中创造大量新的取值敏感方向；
  • 因此，即使隐藏宽度 \(d\) 很大，浅层相对于特征取值的 Jacobian 仍然保持低秩。

B.4. RaBEL 如何打破瓶颈

RaBEL 用紧凑的径向基展开 \(\phi_j(x_{i,j})\in\mathbb{R}^M\) 替换（14）中的标量恒等映射，再投影到 \(\mathbb{R}^d\)：

\[e_{i,j}=\mathrm{LN}(W_{\mathrm{rbf}}\phi_j(x_{i,j})+b_{\mathrm{rbf}})\in\mathbb{R}^d.\tag{28}\]

LN 之前的项 \(W_{\mathrm{rbf}}\phi_j(x_{i,j})\) 可以随着 \(x_{i,j}\) 的变化沿多个方向变化，使特征内部的取值变化在到达骨干网络之前就具有明显更高的有效秩。这正是所期望的机制：在 tokenizer 处注入局部非线性，让早期层能够感知取值，而无需依靠深度来产生曲率。

B.5. 设计启示

ID／位置信号有助于模型识别一个 token 来自哪个特征，但不会增加取值进入网络时的自由度。在标准仿射 token 化下，特征内部的取值变化本质上是低维的（定理 B.1），导致浅层的局部取值敏感性低维（命题 B.2），并产生大量冗余。第 4 节引入的 RaBEL 和重新排序的双向 attention 模块，旨在解决相互补充的失效模式：RaBEL 在 tokenizer 处扩展取值敏感子空间，重新排序的模块则改善条件性，并将跨样本计算路由到用于预测的表示中。
