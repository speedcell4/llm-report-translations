摘要

大语言模型预训练的数据混合配比会显著影响性能，但如何确定有效的混合配比仍不明确。我们提出 RegMix，将其表述为回归任务，从而自动确定性能出色的数据混合配比。RegMix 在不同的数据混合配比上训练许多小模型，使用回归预测未见过的配比的性能，再将预测出的最佳配比用于训练计算量高出多个数量级的大规模模型。

为在实验中验证 RegMix，我们训练了 512 个具有 1M 参数的模型，每个模型使用 1B token，以拟合回归模型并预测最佳数据混合配比。使用这一配比，我们训练一个具有 1B 参数的模型，使用 25B token（即规模增大 1000 倍，训练长度增大 25 倍）；我们发现，它在使用其他配比的 64 个候选 1B 参数模型中表现最佳。此外，在模型规模最高达到 7B、训练 token 数最高达到 100B 的实验中，RegMix 始终优于人工选择，同时只使用 10% 的计算资源就能达到或超过 DoReMi 的表现。

我们的实验还表明：（1）数据混合配比会显著影响性能；（2）与 Wikipedia 等被认为质量较高的数据相比，网络语料与下游性能之间的正相关最强；（3）各域之间的交互关系复杂，常常与常识相悖，因此需要 RegMix 这样的自动化方法；（4）数据混合配比的影响超出了 scaling laws 所能描述的范围。我们的代码见 https://github.com/sail-sg/regmix。

1　引言

大规模公共数据集的可用性，是促成大语言模型（LLM）诞生的关键因素之一。大部分数据都可从互联网上获得，其中包括学术论文（例如 arXiv）、书籍（例如 Project Gutenberg）和代码（例如 GitHub）。在构建最早的一批 LLM 之一 GPT-3（Brown et al., 2020）时，作者已经认识到选择最佳训练数据的重要性，因此基于对 Wikipedia 高质量的判断，对其进行上采样。然而，这类人工数据选择无法有效扩展，而且可能导致次优的选择（Albalak et al., 2024）。随着用于 LLM 预训练的数据规模与多样性不断增长，确定最优数据混合配比变得越来越困难。由此产生了一个关键研究问题：如何以可扩展且高效的方式选择最优数据混合配比？

先前工作（Xie et al., 2023a；Fan et al., 2023；Albalak et al., 2023）使用小规模模型（“代理模型”）来预测大规模语言模型的域权重。这些工作用大量 token（例如 100B）训练代理模型，有时甚至使用与训练 LLM 相同数量的 token，并通过监测训练动态来动态调整数据分配策略。然而，随着 LLM 预训练所用的数据持续增加，这些方法变得低效。为 Llama-3 这样的当前模型训练代理模型，可能需要使用多达 15T token（AI, 2024），其成本和耗时很可能高到不值得采用。1

在本研究中，我们认为，在有限数量的 token 上训练小模型，就足以预测出有效的 LLM 训练数据混合配比。我们的关键假设是数据混合配比的排名不变性：不同配比对模型性能影响的相对排名，在不同模型规模和训练 token 数下保持一致。在这一假设下，关键挑战是从近乎无穷多的可能配比中找到排名最高的配比。为此，我们将数据混合配比选择视为回归任务。我们不穷举每一种可能的配比来训练小模型，而是只训练一组小模型，每个模型使用独特的数据混合配比。根据这些模型的性能及其配比，我们拟合回归模型，预测其他配比的性能。我们的方法允许并行训练小型代理模型，而无需长时间训练单个模型，因此比先前工作更具可扩展性。此外，回归模型能够揭示域间交互关系，有助于理解和整理数据。

为验证 RegMix，我们使用不同的数据混合配比训练了具有 1M 和 1B 参数的模型。2通过在 1B token 上训练 512 个具有 1M 参数的模型，3我们能够预测出 64 个模型中的最优数据混合配比；这些模型的规模大 1000 倍（1B 参数），训练长度长 25 倍（25B token），如图 2 所示。此外，采用 RegMix 优化的数据混合配比所得模型优于人工选择，并且在总计算量更少、可并行训练的情况下，性能达到该方向代表性方法 DoReMi（Xie et al., 2023a）的水平。我们还发现：（1）数据混合配比显著影响下游性能，单项任务的性能差异最高达到 14.6%；（2）与 Wikipedia 相比，通用网络语料（例如 CommonCrawl）与下游任务性能提升之间的正相关最强；（3）域间交互关系复杂，常常与直觉相悖，凸显了 RegMix 等自动化方法的必要性；（4）数据混合配比的影响超出了 scaling laws 所能描述的范围，而 RegMix 通过共同考虑所有域来捕捉这种复杂性。

3　RegMix：将数据混合建模为回归

如图 3 所示，我们的方法包含四个关键步骤：（1）生成随机数据混合配比，并在这些配比上训练小规模代理模型。（2）以配比作为特征、目标值作为标签，拟合线性回归模型。（3）以更大规模模拟数据混合空间，利用回归模型确定目标值最优的配比。（4）使用模拟出的最佳数据混合配比训练大规模模型。

3.1　训练小规模代理模型

第一步是在多种不同的数据混合配比上训练一组小规模代理模型。为减少所需的运行次数，我们希望选择多样的数据混合配比，使每个域的权重覆盖从 0% 到 100% 的极端值。我们通过使用基于 token 分布的 Dirichlet 分布来实现这一目标，从而采样到广泛的取值，让回归模型接触各种极端情况。同时，以 token 分布为基础，可以保证总体数据混合配比在统计上反映数据的可用性。例如，这能避免过度强调某个 token 数占比低于 1% 的域；由于该域没有足够的可用 token，这在大规模训练中不可行。实际中，我们将 token 分布乘以 0.1 到 5.0 之间的一个值，构造不同的稀疏分布和接近均匀的分布，再将这些分布向量用作 Dirichlet 分布的超参数 \(\alpha\)。

将小规模代理模型训练若干步后，我们可以获得几个训练良好的小模型。例如，在我们的主要实验中，每个代理模型包含 1M 参数，并在 1B token 上训练。随后可以选择在各域或基准上评估这些训练后的模型，获得希望优化的目标值。一般而言，目标值可以是某个域上的损失，如图 3 中的 StackExchange 域所示。获得这些目标值之后，就可以以数据混合配比作为特征、目标值作为标签，拟合回归模型。

3.2　拟合回归模型

第二步是使用数据混合配比作为特征、目标值作为标签来拟合回归模型。回归任务是一类常规的监督学习任务，根据输入特征 \(X=(x_1,x_2,\ldots,x_n)\) 预测连续目标变量 \(y\)。目标是找到一个将输入特征最佳地映射到目标变量的函数 \(f\)，使得 \(y=f(X)+\epsilon\)，其中 \(\epsilon\) 表示数据中的误差或噪声。在本文语境中，输入特征 \(X\) 对应数据混合配比中的域权重，目标变量 \(y\) 是我们希望优化的值。使用这些数据，我们训练回归模型，使其学习一个函数，在无需进一步训练的情况下，根据任意数据混合配比预测目标值。

原文第 4 页

线性回归。线性回归模型广泛用于回归任务。它假设输入特征与目标变量之间存在线性关系，可表示为：

\[y=\omega_0+\omega_1x_1+\ldots+\omega_nx_n+\epsilon\tag{1}\]

其中，\(\omega_0\) 为截距，\(\omega=(\omega_1,\ldots,\omega_n)\) 是与各输入特征 \(x_1,\ldots,x_n\) 关联的系数。通常通过普通最小二乘等技术估计系数 \(\omega\)，目标是最小化预测目标值与实际目标值之间的残差平方和。实际中，我们使用带 L2 正则化的线性回归，也称岭回归，通过惩罚 \(\omega\) 的大小来防止过拟合。

LightGBM 回归。LightGBM（Ke et al., 2017）是一种强大的 gradient 提升算法，可用于回归和分类任务。在回归中，LightGBM 学习一个决策树集成来预测目标变量。这一过程由基于 gradient 的优化算法引导，最小化指定的损失函数（例如均方误差）。此外，LightGBM 在设计上追求高效与可扩展，适用于大型数据集。

3.3　模拟与预测

训练回归模型之后，我们就能高效地探索所有可能的数据混合配比空间。使用训练好的模型预测每个候选配比的目标值，可以快速确定产生最佳目标值的输入。这种基于模拟的优化成本相对较低，因为模拟和回归预测在计算上都很快。例如，对 1,000,000 种数据混合配比进行预测，所需 CPU 时间不到 10 秒。

3.4　大规模模型训练

通过模拟确定最佳数据混合配比之后，我们将排名最高的配比推广到使用更多 token 的大规模模型训练中。如图 3 所示，我们直接使用最佳数据混合配比训练更大的模型。实际中，为提高回归预测的稳健性，我们选择排名前 100 的配比并取平均，作为大规模训练的数据混合配比。

5.3　RegMix 的数据混合配比提升下游性能

6　结论

本文提出 RegMix，一种自动选择高性能数据混合配比用于大语言模型预训练的新方法。通过将数据混合问题表述为回归任务，RegMix 训练小模型来预测不同配比的影响，从而高效确定最优组合。我们通过预测 64 个 1B 参数模型中的最佳数据混合配比，证明了 RegMix 的有效性。我们的大规模研究揭示了数据混合配比的影响、损失与下游性能之间的关系，以及人类专家在确定最优配比时面临的挑战。

伦理声明

优化 LLM 预训练数据混合配比会带来若干伦理问题。首先，优化后的数据混合配比可能偏向某些域，这有利于取得更好的性能。然而，某些域可能代表不足或被错误表征，导致训练后的模型在这些域上表现不佳或产生带有偏见的结果。其次，虽然我们的方法旨在高效优化数据混合配比，但寻找最优配比仍需要计算资源，造成较高的能源消耗和环境影响。探索如何进一步降低计算成本是有价值的。

A　更广泛的影响

本文提出 RegMix，一种优化语言模型预训练数据混合配比的新方法。RegMix 的独特贡献在于，创新性地使用超小型代理模型（即 1M 参数）优化语言模型预训练的数据混合配比，这种做法此前在该领域尚未被探索。超小型代理模型的这种新用法，将额外计算开销降低至最终训练成本的 2% 以下，大幅降低了学术预算范围内开展数据混合研究的门槛。通过专注计算效率，并致力于开放科学（即公开所有数据集和训练后的模型），我们认为 RegMix 是推动语言模型预训练研究普及的一项重要进展。

除方法贡献之外，我们的工作还提供了数据混合研究中的若干新实证发现。通过对 64 种不同混合配比训练的 1B 参数模型进行广泛实验，并在 12 个基准上严格评估，我们首次全面展示了不同配比之间显著的性能差异。结果证明，自动数据混合配比优化优于依靠人类直觉的方法；PhilPapers 是一个有趣的深入案例，说明域间交互遵循超出人类直觉的复杂模式。

B　局限性

尽管我们在理解和优化数据混合配比以获得更好性能方面取得了进展，但我们的方法仍有若干局限性。

排名不变性假设。我们目前对排名不变性假设的研究聚焦于从 1M 到 1B 参数的模型规模。虽然我们希望在更大规模上验证这一假设，但要为 3B 模型建立具有统计意义的相关性，需要训练 64 个不同模型，每个使用 50B token，这相当于用 3.2T token 训练一个 3B 模型，显著超出我们的计算资源。

最大模型参数量。我们已验证，可以用小模型预测参数量最高为 1B 的大规模训练运行的最优数据混合配比。然而，通常还会训练具有 7B 或 70B 参数的更大模型（Touvron et al., 2023）。受计算资源限制，我们将更大规模的 RegMix 验证留待未来工作。

基准覆盖。由于 Pile 语料中相关数据稀缺，且我们的 1B 模型规模相对较小，它们在 MMLU 基准（Hendrycks et al., 2021）上的表现接近随机，在 GSM8K（Cobbe et al., 2021）上的表现也几乎可以忽略。因此，我们没有计算验证损失与这些困难基准得分之间的相关性。

无限数据假设。现有的大多数数据混合方法假定每个域都有无限数据可用。虽然我们在第 5.3 节不使用 Pile-CC 的实验中考虑了这一问题，但要系统地将可用数据的影响纳入方法仍有挑战。将我们的方法与 Muennighoff et al. (2023) 提出的数据重复使用衰减系数结合，可能是值得探索的未来工作，有望处理数据可用量有限的场景。

域假设。现有数据混合方法（包括我们的方法）通常假定每个样本所属的域已知。然而，实际中并非总是如此，可能需要先获取域。将样本分配到各域是一项困难任务；当域边界不明确时，这可能使我们的方法难以应用。

tokenizer 假设。所有现有的数据混合方法都需要使用代理模型来获得域权重。然而，这些方法的一项基本假设是，代理模型与大模型使用相同的 tokenizer 和词表大小。将权重泛化到不同 tokenizer 存在显著挑战。

I　排名不变性假设

排名不变性假设认为，不同数据混合配比的相对排名，在不同模型规模（例如从 1M 到 1B 参数）和 token 规模（例如从 1B 到 25B token）之间应保持稳定。这一假设意味着，随着模型规模增大或训练 token 数增加，不同数据混合配比的相对有效性不会显著改变。

K　使用更大的代理模型

我们对代理模型规模如何影响有效性开展了初步研究。具体而言，我们比较两种配置：（1）128 个代理模型，每个具有 1B 参数；（2）512 个代理模型，每个具有 1M 参数（即主要实验中的设置）。两种配置的每个代理模型都使用 1B 训练 token。受计算资源限制，我们无法探索使用更多 1B 参数代理模型的场景，因此仅考察上述配置。

为评估这些配置，我们使用各自优化的数据混合配比，在 100B token 上训练两个 7B 模型，并比较其性能。表 K 汇总的结果表明，两种代理模型设置在下游任务上的平均性能相近。这意味着，即使代理模型数量更少，增大代理模型规模仍能保持有竞争力的性能。然而，鉴于 1B 代理模型并没有显著优于 1M 代理模型，而且计算开销大得多，我们建议优先使用更多的小型代理模型，而非更少的大型代理模型。根据这些发现，我们建议实践者从超小型代理模型（例如本设置中的 1M 参数）开始，优化语言模型预训练的数据混合配比。
